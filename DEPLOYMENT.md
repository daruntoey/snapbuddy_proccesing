# SnapBuddy Deployment Guide

Complete deployment guide for SnapBuddy on Render and Google Cloud.

## Prerequisites

- [ ] GitHub account
- [ ] Render account
- [ ] Google Cloud Platform account with billing enabled
- [ ] Domain name (optional)

## Google Cloud Setup

### 1. Create Google Cloud Project

```bash
# Set project ID
export PROJECT_ID="snapbuddy-production"

# Create project
gcloud projects create $PROJECT_ID --name="SnapBuddy"

# Set as active project
gcloud config set project $PROJECT_ID

# Enable billing
# Visit: https://console.cloud.google.com/billing
```

### 2. Enable Required APIs

```bash
# Enable APIs
gcloud services enable \
  storage.googleapis.com \
  aiplatform.googleapis.com \
  maps-backend.googleapis.com \
  cloudresourcemanager.googleapis.com
```

### 3. Create Service Account

```bash
# Create service account
gcloud iam service-accounts create snapbuddy-service \
  --display-name="SnapBuddy Service Account"

# Grant roles
gcloud projects add-iam-policy-binding $PROJECT_ID \
  --member="serviceAccount:snapbuddy-service@$PROJECT_ID.iam.gserviceaccount.com" \
  --role="roles/storage.admin"

# Create key
gcloud iam service-accounts keys create service-account-key.json \
  --iam-account=snapbuddy-service@$PROJECT_ID.iam.gserviceaccount.com
```

### 4. Create Google Cloud Storage Bucket

```bash
# Create bucket
gsutil mb -p $PROJECT_ID -c STANDARD -l US gs://snapbuddy-uploads/

# Set CORS policy
cat > cors.json << EOF
[
  {
    "origin": ["https://snapbuddy.onrender.com"],
    "method": ["GET", "POST", "PUT", "DELETE"],
    "responseHeader": ["Content-Type"],
    "maxAgeSeconds": 3600
  }
]
EOF

gsutil cors set cors.json gs://snapbuddy-uploads/

# Set public read for uploaded files (optional)
gsutil iam ch allUsers:objectViewer gs://snapbuddy-uploads/
```

### 5. Get Gemini API Key

```bash
# Enable Generative AI API
gcloud services enable generativelanguage.googleapis.com

# Get API key from:
# https://makersuite.google.com/app/apikey
```

### 6. Get Google Maps API Key

```bash
# Enable Maps JavaScript API
gcloud services enable maps-backend.googleapis.com

# Create API key:
# https://console.cloud.google.com/google/maps-apis/credentials

# Restrict the key:
# - Application restrictions: HTTP referrers
# - API restrictions: Maps JavaScript API, Geocoding API
```

## Render Setup

### 1. Push Code to GitHub

```bash
cd snapbuddy
git init
git add .
git commit -m "Initial commit: SnapBuddy AI platform"
git branch -M main
git remote add origin https://github.com/yourusername/snapbuddy.git
git push -u origin main
```

### 2. Connect Repository to Render

1. Go to https://dashboard.render.com
2. Click "New +" → "Blueprint"
3. Connect your GitHub repository
4. Render will detect `render.yaml` and create all services

### 3. Set Environment Variables

#### Backend Service

In Render Dashboard → Backend Service → Environment:

```bash
# Database (auto-set from Render PostgreSQL)
DATABASE_URL=<auto-populated>

# Google Cloud
GOOGLE_CLOUD_PROJECT=snapbuddy-production
GOOGLE_APPLICATION_CREDENTIALS_JSON=<paste entire service-account-key.json contents>
GCS_BUCKET_NAME=snapbuddy-uploads

# Gemini API
GEMINI_API_KEY=<your-gemini-api-key>

# Google Maps
GOOGLE_MAPS_API_KEY=<your-maps-api-key>

# JWT (auto-generated)
JWT_SECRET=<auto-generated-by-render>

# Qdrant (auto-set from Render service)
QDRANT_URL=<auto-populated>

# Redis (auto-set from Render service)
REDIS_URL=<auto-populated>

# CORS
CORS_ORIGINS=https://snapbuddy.onrender.com

# Environment
ENVIRONMENT=production
DEBUG=False
```

#### Frontend Service

In Render Dashboard → Frontend Service → Environment:

```bash
NEXT_PUBLIC_API_URL=https://snapbuddy-backend.onrender.com
NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=<your-maps-api-key>
```

### 4. Deploy

Render will automatically deploy when you push to main:

```bash
git add .
git commit -m "Update configuration"
git push origin main
```

Monitor deployment in Render Dashboard.

## Post-Deployment

### 1. Initialize Database

The database will auto-initialize on first startup. To manually run migrations:

```bash
# Connect to Render shell
render shell snapbuddy-backend

# Run migrations
cd backend
alembic upgrade head
```

### 2. Create Initial Data

Run seed script to create sample photographers:

```bash
# In Render shell
python -m app.scripts.seed_data
```

### 3. Verify Services

Test endpoints:

```bash
# Health check
curl https://snapbuddy-backend.onrender.com/health

# API docs
open https://snapbuddy-backend.onrender.com/docs

# Frontend
open https://snapbuddy.onrender.com
```

### 4. Configure Domain (Optional)

#### For Frontend

1. In Render Dashboard → Frontend Service → Settings
2. Add custom domain
3. Update DNS:
   - Type: CNAME
   - Name: www (or @)
   - Value: snapbuddy.onrender.com

#### For Backend

1. Add custom domain for API
2. Update CORS_ORIGINS environment variable
3. Update NEXT_PUBLIC_API_URL in frontend

## Monitoring & Logging

### Render Logs

View logs in Render Dashboard:
- Backend logs: Render Dashboard → snapbuddy-backend → Logs
- Frontend logs: Render Dashboard → snapbuddy-frontend → Logs

### Google Cloud Monitoring

```bash
# View storage logs
gcloud logging read "resource.type=gcs_bucket" --limit 50

# View API usage
gcloud alpha monitoring dashboards list
```

## Scaling

### Vertical Scaling

In Render Dashboard:
1. Service → Settings → Instance Type
2. Upgrade to higher tier

### Horizontal Scaling

For high traffic:
1. Enable auto-scaling in Render
2. Consider CDN for frontend (Cloudflare/Vercel)
3. Use Redis for caching
4. Optimize database queries

## Troubleshooting

### Database Connection Issues

```bash
# Check DATABASE_URL format
echo $DATABASE_URL

# Should be: postgresql+asyncpg://user:pass@host:port/db

# Test connection
psql $DATABASE_URL
```

### Google Cloud Storage Issues

```bash
# Verify credentials
cat $GOOGLE_APPLICATION_CREDENTIALS

# Test upload
gsutil cp test.txt gs://snapbuddy-uploads/
```

### Qdrant Connection Issues

```bash
# Check Qdrant service status
curl https://snapbuddy-qdrant.onrender.com:6333/

# Verify QDRANT_URL
echo $QDRANT_URL
```

### API Key Issues

```bash
# Test Gemini API
curl -X POST \
  -H "Content-Type: application/json" \
  -d '{"contents":[{"parts":[{"text":"Hello"}]}]}' \
  "https://generativelanguage.googleapis.com/v1beta/models/gemini-pro:generateContent?key=$GEMINI_API_KEY"
```

## Cost Optimization

### Render

- Start with Starter plan ($7/month per service)
- Upgrade only when needed
- Use shared databases for MVP

### Google Cloud

- Use Standard storage class
- Enable lifecycle policies to delete old files
- Set budget alerts
- Use Gemini Flash instead of Pro (cheaper)

## Backup & Recovery

### Database Backups

Render automatically backs up PostgreSQL databases.

Manual backup:

```bash
# Dump database
pg_dump $DATABASE_URL > backup.sql

# Restore
psql $DATABASE_URL < backup.sql
```

### Storage Backups

```bash
# Backup GCS bucket
gsutil -m rsync -r gs://snapbuddy-uploads/ ./backup/
```
